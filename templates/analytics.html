📈 Analytics - Batch Upload (CSV)

📋 Instructions

CSV File Format Requirements:

Your CSV file must include the following columns:

  • amount - Transaction amount
  • hour - Hour of day (0-23)
  • location - Location code (1=Home, 2=Nearby, 3=International)
  • device - Device type (1=Known, 2=Unknown, 3=VPN)
  • payment - Payment method (1=Card, 2=NetBanking, 3=UPI, 4=Crypto)
  • is_new - Is new account (0 or 1)
  • num_items - Number of items in transaction
