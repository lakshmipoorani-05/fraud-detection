ℹ️ Model Overview

Random Forest Classifier

Our fraud detection system uses a Random Forest Classifier, an ensemble learning method that operates by constructing multiple decision trees during training and outputting the class that is the mode of the classes of the individual trees.

Key Features:

  • Transaction amount
  • Time of transaction
  • Location data
  • Device information
  • User behavior patterns
